# BioHackrXiv preprints in Europe PMC: possible problems

Generated on 2026-11-25 by `make europepmcReport` in the [BioHackrXiv index](https://index.biohackrxiv.org), from the Europe PMC records found with the query `PUBLISHER:"BioHackrXiv"`. The index lists 175 preprints; Europe PMC has 202 records for this query.

BioHackrXiv preprints are hosted by OSF. Each version of a preprint has its own DOI (`10.37044/osf.io/<id>_v1`, `_v2`, ...), and there is also a DOI without version suffix (`10.37044/osf.io/<id>`) that resolves to the latest version. Older preprints (before 2025) only have the DOI without suffix.
